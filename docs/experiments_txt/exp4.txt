Experiment: Morphological Analysis and Word Generation
Aim
To perform morphological analysis and word generation for any given text.
Theory
Introduction
Morphology is the study of the structure and formation of words. In Natural Language Processing (NLP), morphological analysis is the
process of breaking words into their basic meaningful components and identifying their grammatical properties.
For example, the words:
develop
developed
developing
developer
development
are morphologically related because they are derived from the root word develop.
Morphological analysis is useful in NLP because the same concept can appear in a text in several different word forms. Identifying the base
form of these words helps computers process and understand text more effectively.
Morphological Analysis
Morphological analysis identifies the root word, base form, prefixes, suffixes, and grammatical information associated with a word.
For example:
Word Base FormMorphological Information
developed develop Past tense verb
developing develop Present participle
developersdeveloper Plural noun
projects project Plural noun
applicationsapplication Plural noun
managed manage Past tense verb
In this experiment, lemmatization is used to obtain the meaningful base form of words. Part-of-Speech (POS) tagging is also used to identify
whether a word is a noun, verb, adjective, adverb, etc.
Word Generation
Word generation is the process of generating different forms of a word from a root or base word.
For example, from the root word develop, we can generate:
develop
develops
developed
developing
developer
development
Similarly, from manage, we can obtain:
manage
manages
managed
managing
manager
management
Word generation demonstrates how prefixes, suffixes and grammatical changes can produce different forms of a word.
NLP Techniques Used
1. Tokenization
Tokenization divides a sentence or document into smaller units called tokens.

For example:
Python developer has experience
becomes:
Python
developer
has
experience
2. Part-of-Speech Tagging
Part-of-Speech (POS) tagging assigns a grammatical category to each word.
Common POS tags include:
Tag Meaning
NN Noun
NNS Plural Noun
VB Verb
VBD Past Tense Verb
VBG Verb ending in -ing
JJ Adjective
RB Adverb
NNP Proper Noun
For example:
developed → VBD
projects → NNS
Python → NNP
3. Lemmatization
Lemmatization converts a word into its meaningful base or dictionary form.
Examples:
text projects → project applications → application developed → develop managed → manage
Lemmatization is useful because it treats different grammatical forms of a word as related to the same base word.
4. Root Word
A root or base word represents the fundamental form from which other related words can be derived.
For example:
develop
   |
   ├── developed
   ├── developing
   ├── developer
   └── development
Applications
Morphological analysis and word generation can be used in many NLP applications:
1. Resume Analysis – identifying different forms of skills and job-related terms.
2. Search Engines – matching related forms of search terms.
3. Information Retrieval – improving document and keyword matching.
4. Text Classification – improving text representation.
Advantages
Helps identify the base form of words.
Reduces the number of different word forms that need to be processed.
Improves text processing and information retrieval.
Helps identify related words in resumes.
Limitations
Lemmatization may require POS information for accurate results.
Simple suffix-based word generation may produce invalid words.
Some words have irregular morphological forms.

Technical terms and abbreviations in resumes may not be handled perfectly.

from nltk.corpus import wordnet
def get_wordnet_pos(tag):
    if tag.startswith('J'):
        return wordnet.ADJ
    elif tag.startswith('V'):
        return wordnet.VERB
    elif tag.startswith('N'):
        return wordnet.NOUN
    elif tag.startswith('R'):
        return wordnet.ADV
    else:
        return wordnet.NOUN
morphological_results = []
for word, tag in pos_words:
    wn_tag = get_wordnet_pos(tag)
    lemma = lemmatizer.lemmatize(word.lower(), wn_tag)
    morphological_results.append((word, tag, lemma))
print("Word\t\tPOS\tLemma")
print("-" * 40)
for word, tag, lemma in morphological_results[:20]:
    print(f"{word:15} {tag:5} {lemma}")
def generate_words(root):
    words = [
        root,
        root + "s",
        root + "ed",
        root + "ing",
        root + "er",
        root + "ment"
    ]
    return words
root = "develop"
generated = generate_words(root)
print("Root word:", root)
print("Generated words:")
for word in generated:
    print(word)

Aim
Exploratory Data Analysis of a given text (Word Cloud).
Theory
Exploratory Data Analysis (EDA) is the process of analyzing and visualizing data to understand its main characteristics, patterns, and
underlying structure before applying further NLP techniques. For text data, EDA typically involves:
1. Basic statistics – Number of documents, word counts, character counts, average document length.
2. Category/class distribution – Understanding how the text data is spread across different classes or labels.
3. Word frequency analysis – Identifying the most frequently occurring words after removing stopwords.
4. Word Cloud visualization – A visual representation of text data where the size of each word indicates its frequency; more frequent
words appear larger and bolder.
A Word Cloud is one of the most popular EDA tools for text data because it gives an instant, intuitive sense of which words dominate a
document or corpus, without having to read through all the text manually.
Application
Quickly summarizing large text corpora (resumes, reviews, articles, tweets)
Identifying dominant themes/keywords in a dataset
Comparing vocabulary across different categories or classes
Preliminary step before building NLP models (helps spot noisy or irrelevant frequent terms)
Advantages
Simple, fast, and visually intuitive
Requires no complex modeling — good first step in any text analysis pipeline
Helps identify important keywords and irrelevant noise (e.g. common but meaningless words)
Limitations
Does not capture context, grammar, or word relationships
Can be misleading if stopwords/noise aren't properly removed
Word size is based purely on frequency, not importance or sentiment

stop_words = set(stopwords.words('english'))
def preprocess(text):    text = text.lower()    text = re.sub(r'[^a-z\s]', ' ', text)    text = re.sub(r'\s+', ' ', text)    tokens = word_tokenize(text)    tokens = [word for word in tokens if word not in stop_words and len(word) > 2]    return " ".join(tokens)
df['clean_resume'] = df['Resume'].apply(preprocess)df[['Resume', 'clean_resume']].head()
